## 自己紹介

こんにちは、**nnna1224** です。  
私は普段、**山梨大学**の学生としてコンピュータ科学を学び、研究しています 🍐

コンピュータ科学の分野では主に、**自然言語処理、UI/UXデザイン、ゲーム開発、Webインフラ**などに取り組んでいます。  
また他にも、個人制作や共同制作活動として、**イラストや小説を含む芸術作品**の制作など、幅広い分野での活動も行っています。

機能的・高性能・正確なだけではなく、ユーザーや視聴者の文脈・感情・体験・経験にも配慮したシステムや作品を作ることに関心があります。

[ゲーム制作サークル G^2(ジーツー)](https://g-2-yama.github.io) に所属しており、オリジナルゲームを中心とした創作活動を行っています。
